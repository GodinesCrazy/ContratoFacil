# Roadmap Técnico — ContratoFácil

## Fase 1: MVP (Actual)
- [x] Arquitectura base y monorepo.
- [x] Configuración de base de datos e infraestructura CI/CD.
- [ ] Solución de errores de build y generación de Prisma.
- [ ] Implementación visual del frontend y dashboard.
- [ ] Autenticación de usuarios.
- [ ] Generación de PDF con PDFKit.
- [ ] Simulación de pago y descargas con marca de agua.

## Fase 2: Pack Arriendo Seguro
- Implementar los 5 documentos principales: Contrato de arriendo, Acta de entrega, Inventario, Anexo modificación, Aviso término.
- Mejorar los formularios con guías paso a paso.

## Fase 3: SaaS Mensual
- Integración de pasarela de pagos real (Suscripciones o pago por documento).
- Control de vencimientos y sistema de recordatorios (Email/Notificaciones).

## Fase 4: Firma Electrónica
- Integración con proveedor local o internacional para firmas legalmente válidas en Chile.
- Trazabilidad y validación de hash de documentos.

## Fase 5: Integración IA y Gestión Avanzada
- IA para asistencia en redacción de cláusulas (marcado como asistente documental, no abogado).
- Panel de gestión para corredores e inmobiliarias.
